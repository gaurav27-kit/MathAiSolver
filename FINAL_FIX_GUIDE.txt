================================================================================
                          WHY IS THIS HAPPENING?
================================================================================

The backend code uses these new packages:
- helmet (security headers)
- joi (input validation)
- express-rate-limit (rate limiting)

If these aren't installed, the backend will crash or behave unexpectedly.

The server.js file tries to load them:
    const helmet = require("helmet");
    const rateLimit = require("express-rate-limit");

If they don't exist → Error or 405

Solution: Use server-simple.js which doesn't need these packages

================================================================================
                          WHICH SERVER FILE TO USE?
================================================================================

Use server-simple.js if:
✓ npm install hasn't been run
✓ You're getting 405 errors
✓ You want to test quickly
✓ Dependencies won't install

Use server.js (normal) if:
✓ npm install completed successfully
✓ You want full security features
✓ You're deploying to production
